# Expense Tracker 0.4.8

- Grouped Android APKs/manifests, macOS packages/appcasts and Windows bundles/appcasts into `release/android/`, `release/mac/` and `release/window/`. Earlier artifacts are preserved; GitHub download names and updater URLs remain unchanged.
- Added native-host release commands with focused checks, automatic desktop feed activation, updater payload signing and appcast generation. Public desktop finalization requires native signing verification.
- Added Android staging verification for package ID, ARM64 architecture, increasing version code and continuity with the previous release certificate.
- Updated packaging, publishing and native validation workflow to consume platform folders directly. Publication now requires both signed desktop feeds and every platform artifact by default.

Status: source release preparation only. The original Android keystore configuration, desktop updater keys, Developer ID/notarization and Windows Authenticode setup are required before producing a complete public release. Existing 0.4.7 validation builds do not acquire updates from these source changes; a newly configured build must first be installed manually. Native installation and signed upgrade verification remain pending.
