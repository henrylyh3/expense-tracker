Automatic Android update prompts are now available.

- The app checks for a newer release when it opens.
- Choose Update now to download and verify the signed APK, or Later to keep using your current version.
- Android may ask you to allow updates from Expense Tracker before opening the update installer.
- Offline checks do not block expense tracking. Updates keep your existing ledger.

Install this version manually once to enable future in-app updates. iOS installation through this Android updater is not supported.
