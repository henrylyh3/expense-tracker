# Expense Tracker 0.4.16

- Export or share JSON for selected trips or the entire ledger.
- Import trips into the current ledger. When a trip name matches, merge into the existing trip or create a numbered copy such as Personal (1).
- Home shows spending summaries and charts. Open History to browse transactions.
- Shared trips shows the trip name on guest invitations and lets you copy the original guest link or invitation code.

Desktop packages use personal-use signing. macOS uses an ad-hoc signature, and Windows installation may show a publisher warning. Both desktop updater payloads are signed.
