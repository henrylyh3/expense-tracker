# v0.4.9+18

Adds a mobile browser guest page using the existing encrypted Discord relay, with a visible local pending queue and foreground sync. Hosts can create private web invitations lasting 24 hours, seven days or 30 days. Expiry is stored and enforced by the host; existing native invitations remain compatible. Ledger ownership, application IDs, data paths and signing keys are unchanged.

Source validation includes Flutter analysis, focused Discord sharing tests, native/WebCrypto packet compatibility and focused browser relay tests. Browser UI checks use fictional data and do not establish real Discord or Safari acceptance.

This version is not a complete public native release until all Android, macOS and Windows artifacts are signed and verified. Original Android release credentials and desktop signing/notarization configuration remain required. Do not publish partial artifacts as a complete release.
