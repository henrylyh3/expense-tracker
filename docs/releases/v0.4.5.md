- Currency templates now include 165 current monetary currencies, bundled offline and sorted by currency code.
- Type a currency code or name to search instead of scrolling.
- Removed the decimal-places control from currency settings.
- Foreign expenses accept fractional amounts, including JPY, up to six decimal places. MYR totals remain at two decimals.
- Duplicate currency names are rejected, ignoring case and repeated spaces. Different names can still use the same currency code.
- Existing amounts are preserved during upgrade; backups now retain each expense's amount precision.
