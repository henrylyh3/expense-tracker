# Schema snapshots

`drift_schema_v1.json` is the real initial schema generated by Drift. The helper
in test/generated_migrations/ is generated from this snapshot. Baseline tests and
`bash tool/check_schema.sh` verify it against the current database.

Retain every released version for upgrade tests. Never overwrite historical
snapshots to silence a mismatch. The current ledger.drift source is not a
substitute for a historical snapshot. See the
[migration policy](../lib/core/database/migrations/README.md) for new-version commands.
